1. 함께 받은 CODEX-INSTALL-SLIDES.html 설치 설명서를 엽니다.
2. PC의 Codex에서 Astra를 선택하고 아래 문장을 붙여 넣습니다. ZIP을 받았다면 압축을 풀어 Codex에서 그 폴더를 열어도 됩니다.
3. GitHub 가입·로그인은 필요 없습니다. 공개 저장소 내려받기에는 계정이 필요 없습니다.
4. 자막은 GPT Realtime(고급) 또는 GPT-6 Luna(가성비) 중 앱에서 고르고, 크롬 댓글 번역(선택)은 GPT-6 Luna입니다. 둘 다 API라 노트북·Mac 사양과 상관없이 같은 가벼운 설치이고, 큰 모델을 내려받지 않습니다.
5. Mac은 직접 하는 단계가 있습니다: Python 3.12와 BlackHole 2ch 설치 → '오디오 MIDI 설정'에서 다중 출력 장치(스피커+BlackHole 2ch) 만들기 → 시스템 설정 → 사운드 → 출력에서 그 장치 선택 → setup-mac.sh 실행(Codex가 해도 됨) → Start API Captions.command 실행 후 소리 장치 BlackHole 2ch 선택, 마이크 접근 허용.
6. API 키: 11월 6일까지는 전달받은 체험 키(여러 명이 함께 쓰는 공유 키, 다른 사람에게 다시 전달하지 않음), 그 뒤에는 본인 OpenAI 키를 앱 입력칸에 직접 넣습니다.
7. Realtime은 켜 둔 동안 조용해도 비용이 나갑니다(1시간 약 $2, 앱 추정). 다 보면 중지를 누르고, 소리가 60초 동안 없으면 앱이 자동으로 멈춥니다. 다시 보려면 번역 시작을 누릅니다.

https://github.com/chiwon3160-byte/korean-live-captions-api 이 번역앱을 내 PC에 설치해 줘. CODEX-INSTALL.md 전체를 먼저 읽고 따라 해. 내 Windows/Mac 환경에 맞게 설치·디버깅·실행 확인을 진행해 줘. API 키는 내가 앱에 직접 넣을게. 키를 읽거나 출력하지 마. 유료 번역 테스트는 내가 시작 버튼을 누를 때 짧게 확인해 줘.

ZIP 폴더를 연 경우 첫 URL 대신 '이 폴더의 번역앱을 내 PC에 설치해 줘'라고 입력합니다.
크롬 댓글 번역을 쓰려면 설치 뒤 Codex에게 '크롬 댓글 번역 확장도 연결해 줘'라고 말합니다(CODEX-INSTALL.md 5절).
Mac 지원은 모의 테스트까지만 확인했고 실제 Mac에서는 아직 실행해 보지 않았습니다. 막히면 Codex가 디버깅합니다.
