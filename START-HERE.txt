https://github.com/chiwon3160-byte/korean-live-captions-api 이 번역앱을 내 PC에 설치해 줘. 저장소의 CODEX-INSTALL.md 전체를 먼저 읽고 따라 해. 내 Windows/Mac 환경에 맞게 필요한 설치와 호환성 수정·디버깅을 진행하고 실제로 확인된 실행 방법과 바로가기를 만들어 줘. API 키는 내가 앱의 마스킹 입력란에 직접 넣을게. 키를 읽거나 출력하지 마. 유료 번역 테스트는 내가 시작 버튼을 누를 때 짧게 확인해 줘.

ZIP 폴더를 연 경우 첫 URL 대신 '이 폴더의 번역앱을 내 PC에 설치해 줘'라고 입력합니다.
현재 소스는 Windows 중심입니다. Mac에서는 추가 이식과 실제 소리 검증이 필요하며 자동 성공을 보장하지 않습니다.
