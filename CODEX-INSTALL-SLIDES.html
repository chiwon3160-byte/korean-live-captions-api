설치 ④ | Mac

Mac은 소리를 앱으로 넘기는 설정을
한 번 손으로 합니다

  • ① Python 3.12와 BlackHole 2ch(무료 가상 오디오 장치) 설치 — Mac 암호를 물으면 직접 넣습니다.
  • ② “오디오 MIDI 설정” 앱 → + → 다중 출력 장치 → 스피커(또는 이어폰)와 BlackHole 2ch 체크.
  • ③ 시스템 설정 → 사운드 → 출력에서 그 다중 출력 장치를 고릅니다.
  • ④ 앱 폴더에서 setup-mac.sh를 한 번 실행합니다(Codex가 대신 실행해도 됨).
  • ⑤ “Start API Captions.command” 더블클릭 → 소리 장치에서 BlackHole 2ch 선택 → 마이크 접근을 물으면 허용.

Mac은 아직 실제 기기 검증 전입니다. 첫 설치 때 Codex가 확인·수정하며 진행합니다. 자막 모델 두 가지와 댓글 번역 모두 Mac에서도 같습니다.
