# 한국어 실시간 자막 — API 버전

PC에서 재생하는 영어·스페인어 영상의 소리를 인식하고 한국어 자막으로 보여줍니다. 기본 번역 모델은 **Luna 6 · 추론 none**입니다. 음성 인식은 PC에서, 번역은 본인의 API 키로 처리합니다.

## 처음 설치할 때

**Codex에 설치를 맡기는 경우:** [START-HERE.txt](START-HERE.txt)의 문장을 붙여 넣습니다. 상세 설치·Mac 이식 지침은 [CODEX-INSTALL.md](CODEX-INSTALL.md), 순서별 안내는 [설치 슬라이드](CODEX-INSTALL-SLIDES.html)에 있습니다. 아래는 현재 Windows 수동 설치 절차입니다. 메타프롬프트 제공이 Mac 지원 완료를 뜻하지는 않습니다.

필요한 환경은 **Windows 11 64비트, Python 3.12 64비트, NVIDIA GPU와 정상 작동하는 드라이버**입니다. Python 설치 시 Python Launcher를 포함하세요. API 번역을 사용해도 PC 음성 인식용 GPU가 필요합니다. CPU 전용·AMD/Intel GPU·Mac은 현재 지원하지 않습니다.

1. 배포 ZIP을 원하는 로컬 폴더에 모두 풉니다. ZIP 안에서 바로 실행하지 마세요.
2. [Python 3.12](https://www.python.org/downloads/windows/)를 설치합니다.
3. 압축을 푼 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-api.ps1
   ```

4. 설치가 끝나면 **Start API Captions.vbs**를 두 번 클릭합니다.

이 설치 경로는 음성 모델과 Python 패키지만 준비합니다. **Ollama나 Qwen 설치는 필요 없습니다.** 음성 모델은 약 1.62GB이며 패키지·다운로드 임시 파일에 추가 디스크 공간이 필요합니다. 모델과 `.venv`는 배포본에 포함하지 않습니다. 설치가 중단되면 같은 명령을 다시 실행할 수 있습니다.

VBS 실행이 차단된 환경에서는 아래 명령으로 앱을 엽니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch-api.ps1
```

## API 키를 넣고 시작하기

### 본인의 OpenAI API 키를 준비합니다

1. [OpenAI Platform](https://platform.openai.com/)에 본인 계정으로 로그인합니다. ChatGPT 구독과 API 사용료는 별도입니다.
2. Platform의 조직 결제 설정에서 사용 가능한 크레딧이나 결제 수단을 확인합니다. 결제가 필요하면 금액과 자동 충전 여부를 읽고 직접 선택합니다. 가입만으로 무료 API 사용이 보장되지는 않습니다.
3. 프로젝트 선택 메뉴에서 본인 번역앱용 프로젝트를 선택하거나 만듭니다. 회사 관리 계정에서 권한이 없다면 관리자에게 문의합니다.
4. 선택한 프로젝트의 **API Keys → Create new secret key**에서 알아보기 쉬운 이름으로 키를 만듭니다. 키 권한을 제한하는 경우 사용할 번역 API에 필요한 권한을 허용해야 하며, Read Only 키는 번역 요청에 맞지 않습니다.
5. 표시된 키를 직접 복사하여 앱의 가려진 API 키 입력칸에 붙여 넣습니다. 새 키는 다시 전체 값을 볼 수 없으므로 필요하면 본인의 안전한 비밀값 보관 도구에 보관합니다. Codex 채팅·GitHub·스크린샷에는 넣지 않습니다.
6. 프로젝트 **Limits → Spend → Edit spend limit**에서 원하는 월별 금액을 정하고, 사용 차단을 원하면 **Enforce a hard limit**을 켠 뒤 저장합니다. 알림만 설정하면 요청이 차단되지 않습니다. 적용 지연으로 소액 초과할 수 있고 월마다 초기화됩니다.
7. 앱에서 설정을 적용하고 짧게 번역한 뒤 중지합니다. [Usage](https://platform.openai.com/usage)에서 프로젝트를 선택하여 사용량을 확인합니다. 앱 예상 비용과 최종 청구액은 다를 수 있습니다.

현재 배포본에는 체험용 API 키가 포함되지 않습니다. 체험 지원 여부와 별개로 본인 키를 넣어 사용할 수 있습니다.

공식 안내: [프로젝트·키 발급](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform), [월별 강제 한도](https://developers.openai.com/api/docs/guides/spend-limits). 화면 이름은 계정·권한·제품 변경에 따라 다를 수 있습니다.

### 앱에 입력합니다

1. 앱의 **소리·표시 설정**에서 OpenAI와 **Luna 6**가 선택되어 있는지 확인합니다. 키가 없는 첫 실행에는 설정창이 열립니다.
2. [OpenAI API 키 관리](https://platform.openai.com/api-keys)에서 준비한 **본인의 키**를 API 키 칸에 붙여 넣습니다. 키는 가려서 표시됩니다.
3. **번역 설정 적용 → 닫기 → 번역 시작**을 누릅니다.
4. 영상을 재생합니다. 소리가 나는 장치가 **기본 출력 · 스피커/이어폰**과 일치해야 합니다. 입력 소리 막대가 움직이는지 확인하세요.

키는 앱이 자동으로 저장하지 않습니다. 앱을 종료했다가 다시 열면 다시 입력합니다. API 계정에서 해당 모델에 접근할 수 있어야 하며 사용 가능한 잔액·한도가 필요합니다. 키를 채팅·스크린샷·Git·배포 ZIP에 넣지 마세요.

직접 관리하는 PC에서 키 재입력을 줄이려면 앱 폴더의 `.env.local`에 `OPENAI_API_KEY=` 항목을 직접 저장할 수 있습니다. 이 파일은 공유하거나 Git에 올리지 마세요. 키를 읽는 순서는 화면 입력 → 프로세스 환경변수 → `.env.local`입니다. 다른 사람에게는 자신의 키가 없는 원본 배포 ZIP을 전달하세요.

## 모델 변경

**중지 → 소리·표시 설정 → 번역 모델 메뉴 클릭 → 원하는 모델 선택 → 번역 설정 적용 → 닫기 → 번역 시작** 순서입니다. 모델 이름을 직접 입력할 필요가 없습니다.

| 선택 | 추론 설정 |
|---|---|
| Luna 6 — 기본값 | none 또는 low |
| Terra 6.1 | none 또는 low |
| SOL 6.1 | low |

Luna 6 기본값은 실사용 속도를 우선한 선택입니다. 모든 영상에서 가장 정확한 모델이라는 뜻은 아닙니다. 부정·숫자·전문 용어 등 중요한 내용은 원문과 함께 확인하세요.

## 사용 비용과 화면 조작

- 창에 **이번 실행의 API 누적 예상 비용(USD)**과 모델별 요청·성공 수, 입출력 토큰이 표시됩니다.
- 중지·새 영상·모델 변경 후에도 누적되며, 앱을 완전히 종료하면 초기화됩니다. 과거 실행의 비용은 합산하지 않습니다.
- API 응답의 사용량으로 계산합니다. 사용량을 못 받은 요청이나 단가를 모르는 모델은 **비용 미확인**으로 표시합니다. 캐시 할인·세금은 반영하지 않으며 제공사의 최종 청구액과 다를 수 있습니다.
- 이미 번역 중이면 시작 버튼은 **번역 중**으로 표시됩니다. 설정을 바꾸려면 먼저 **중지**를 누르세요.
- 새 영상은 **새 영상** 또는 `Ctrl+Shift+R`, 중지는 `Ctrl+Shift+S`입니다. 영상 위 자막은 별도로 이동하거나 위치를 고정할 수 있습니다.

## 소리가 안 들어올 때

**중지 → 소리·표시 설정 → 새로고침 → 실제 소리가 나오는 장치 선택 → 번역 시작**으로 다시 연결합니다. Windows 기본 출력과 브라우저/앱별 출력이 다를 수 있습니다. 이어폰·USB 장치를 바꾼 뒤에는 다시 선택하세요. 영상 일시정지·브라우저 음소거도 확인합니다. 소리 막대가 움직이지 않으면 먼저 입력 장치를 점검하세요.

## 전송 범위와 알려진 제한

- 마이크 대신 선택한 **출력 장치의 전체 소리**를 받습니다. 특정 브라우저 탭 하나만 분리하는 기능은 아닙니다.
- 음성 인식은 PC의 Whisper에서 처리합니다. API에는 전사된 원문과 최근 문맥을 보내며 음성 파일은 보내지 않습니다. 자막·음성을 자동 저장하지 않습니다.
- 댓글 API 전송은 기본 꺼짐입니다. 별도로 켜면 음성 번역을 중지한 동안에도 댓글 요청으로 비용이 발생할 수 있습니다.
- API 요청을 자동 재시도하지 않습니다. 중지를 눌러도 이미 제출한 요청과 과금은 취소되지 않을 수 있습니다.
- 개발 PC에서 실행·번역을 확인했지만, **새 PC의 처음부터 끝까지 설치는 아직 검증하지 않았습니다.** 최소 VRAM과 모든 장치의 성능도 검증하지 않았습니다. 단일 EXE가 아닌 소스·설치 도구 배포본입니다.

## Realtime 음성 직접 번역 선택
**중지 → 소리·표시 설정 → 번역 방식 OpenAI Realtime · 음성 직접 번역 → 번역 설정 적용 → 닫기 → 번역 시작**으로 선택합니다. 기본값 Luna 6는 유지됩니다. 같은 OpenAI 키를 사용하며 계정에 모델 이용 권한이 있어야 합니다.

이 모드는 PC 음성 인식을 거치지 않고 선택한 출력 장치의 소리를 무음까지 OpenAI로 전송합니다. `gpt-realtime-translate`가 한국어를 연속 출력하며, 앱은 번역 음성을 재생하지 않고 자막만 표시합니다. 원문 자막·댓글 번역·추론 설정은 지원하지 않습니다. 중지는 연결을 종료하고 새 영상은 이전 문맥을 비우기 위해 새 연결을 엽니다.

[공식 단가](https://developers.openai.com/api/docs/models/gpt-realtime-translate)는 **음성 1분 $0.034 / 10분 $0.34 / 1시간 $2.04**입니다(2026-10-30 확인). Realtime 서버 이벤트에 토큰 사용량이 없어 창의 비용은 **전송 음성 시간 기준 예상치**입니다. 무음 전송도 시간에 포함되며 최종 청구액과 다를 수 있습니다. 원문 전사 기능은 꺼서 별도 전사 비용을 피합니다.

연결 방식은 [공식 Realtime 번역 가이드](https://developers.openai.com/api/docs/guides/realtime-translation)를 따릅니다. 속도·품질·계정별 실연결은 사용자가 직접 시험할 단계입니다. 모의 이벤트·수명주기 테스트와 실제 서비스 시험은 다릅니다. API 기본 설치는 Luna용 음성 모델도 준비하므로 여전히 NVIDIA 조건을 확인합니다.
