# 한국어 실시간 자막 — 팀 배포판 (API 전용)

PC에서 재생하는 영어·스페인어 영상의 소리를 받아 한국어 자막으로 보여줍니다. **자막은 GPT Realtime(실시간 고급, 1시간 약 $2) 또는 GPT-6 Luna(가성비, 1시간 약 $0.2, 자막이 2~3초 더 늦음) 중 골라 쓰고, 크롬 TikTok 댓글 번역(선택)은 GPT-6 Luna**로 처리합니다. 둘 다 API라 노트북·Mac 사양이나 그래픽카드와 상관없이 같은 가벼운 설치이고, 큰 모델을 내려받지 않습니다. 앱 폴더의 `API-ONLY-EDITION.txt`는 이 배포판을 표시하는 파일이니 지우지 마세요.

## 처음 설치할 때

**Codex에 설치를 맡기는 경우:** [START-HERE.txt](START-HERE.txt)의 문장을 붙여 넣습니다. 상세 설치 지침은 [CODEX-INSTALL.md](CODEX-INSTALL.md), 순서별 안내는 [설치 슬라이드](CODEX-INSTALL-SLIDES.html)에 있습니다. 아래는 직접 설치하는 절차입니다. GitHub 가입은 필요 없습니다(공개 저장소 내려받기에는 계정이 필요 없음).

### Windows (어떤 PC든 같음)

**Windows 11 64비트와 Python 3.12 64비트**가 필요합니다. Python 설치 시 Python Launcher를 포함하세요.

1. 배포 ZIP을 원하는 로컬 폴더에 모두 풉니다. ZIP 안에서 바로 실행하지 마세요.
2. [Python 3.12](https://www.python.org/downloads/windows/)를 설치합니다.
3. 압축을 푼 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-api.ps1
   ```

4. 설치가 끝나면 **Start API Captions.vbs**를 두 번 클릭합니다.

설치는 Python 패키지만 준비합니다. 음성 모델·CUDA·Ollama는 받지 않으며 그래픽카드가 있어도 같습니다. `.venv`는 배포본에 포함하지 않습니다. 설치가 중단되면 같은 명령을 다시 실행할 수 있습니다.

VBS 실행이 차단된 환경에서는 아래 명령으로 앱을 엽니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch-api.ps1
```

### Mac (직접 하는 5단계)

Mac은 영상 소리를 바로 가져올 방법이 없어, 무료 가상 오디오 장치 **BlackHole 2ch**로 소리를 한 갈래 더 보내 앱이 받습니다. 스피커 소리는 그대로 들립니다.

1. [Python 3.12](https://www.python.org/downloads/macos/)와 [BlackHole 2ch](https://existential.audio/blackhole/)를 설치합니다(BlackHole 설치에는 Mac 암호가 필요할 수 있습니다).
2. **오디오 MIDI 설정** 앱을 열고 왼쪽 아래 **+ → 다중 출력 장치 생성**을 누른 뒤, 쓰는 스피커(또는 이어폰)와 **BlackHole 2ch**를 모두 체크합니다.
3. **시스템 설정 → 사운드 → 출력**에서 방금 만든 **다중 출력 장치**를 고릅니다. 이 상태에서는 키보드 볼륨 키가 듣지 않을 수 있으니 영상 플레이어의 볼륨으로 조절합니다. 번역을 안 쓸 때는 출력을 원래 스피커로 되돌려도 됩니다.
4. 압축을 푼 폴더에서 터미널로 `bash setup-mac.sh`를 한 번 실행합니다.
5. **Start API Captions.command**를 두 번 클릭합니다(처음 한 번은 Control-클릭 → 열기가 필요할 수 있습니다). 터미널 창은 앱을 쓰는 동안 열어 둡니다. 소리 장치 목록에서 **BlackHole 2ch**를 고르고, 마이크 접근을 묻는 창이 뜨면 허용합니다(앱은 BlackHole 입력만 열고 실제 마이크는 고르지 않습니다).

Mac 지원은 개발 PC의 모의 테스트까지만 확인했고 **실제 Mac에서는 아직 실행해 보지 않았습니다.** 전역 단축키는 Windows에서만 동작하므로 Mac에서는 창의 **새 영상·중지** 버튼을 씁니다.

## API 키를 넣고 첫 자막 보기

배포본에는 API 키가 들어 있지 않습니다. **11월 6일까지는 따로 전달받은 체험 키**를 씁니다. 여러 명이 함께 쓰는 공유 키이므로 다른 사람에게 다시 전달하지 말고, 채팅·캡처에도 넣지 마세요. 체험 기간이 끝나면 아래 **부록: 본인 OpenAI 키 만들기**대로 만든 본인 키를 넣습니다.

1. 앱의 **소리·표시 설정**에서 번역 방식이 **OpenAI Realtime · 음성 직접 번역**인지 확인합니다. 키가 없는 첫 실행에는 설정창이 열립니다.
2. API 키 칸에 키를 붙여 넣습니다. 키는 가려서 표시됩니다.
3. **번역 설정 적용 → 닫기 → 번역 시작**을 누릅니다.
4. 영상을 재생합니다. 소리가 나는 장치가 **기본 출력 · 스피커/이어폰**(Mac은 **BlackHole 2ch**)과 일치해야 합니다. 입력 소리 막대가 움직이는지 확인하세요.
5. 다 보면 **중지**를 누릅니다.

키는 앱이 자동으로 저장하지 않습니다. 앱을 종료했다가 다시 열면 다시 입력합니다. 직접 관리하는 PC에서 재입력을 줄이려면 앱 폴더의 `.env.local`에 `OPENAI_API_KEY=` 항목을 직접 저장할 수 있습니다(읽는 순서: 화면 입력 → 프로세스 환경변수 → `.env.local`). 이 파일은 공유하거나 Git에 올리지 마세요.

## Realtime 자막 — 비용과 자동 중지

이 모드는 선택한 출력 장치의 소리를 **무음까지** OpenAI로 전송합니다. `gpt-realtime-translate`가 한국어를 연속 출력하며, 앱은 번역 음성을 재생하지 않고 자막만 표시합니다. 원문 자막·추론 설정은 지원하지 않습니다. 중지는 연결을 종료하고 새 영상은 이전 문맥을 비우기 위해 새 연결을 엽니다.

- **켜 둔 동안 조용해도 비용이 나갑니다.** [공식 단가](https://developers.openai.com/api/docs/models/gpt-realtime-translate)는 음성 1분 $0.034 / 10분 $0.34 / 1시간 $2.04입니다(2026-10-30 확인). 창의 비용은 보낸 음성 시간으로 앱이 계산한 **예상치**이며 최종 청구액과 다를 수 있습니다.
- **소리가 60초 동안 없으면 번역을 자동으로 멈춥니다(비용 절약).** 상태 줄에 "소리가 60초 동안 없어 번역을 멈췄습니다"가 뜨면 다시 볼 때 **번역 시작**을 누르면 됩니다. 아주 작은 소리·배경음도 소리로 봅니다. 그 60초 동안의 무음도 과금됩니다.
- 체험 키는 함께 쓰는 예산입니다. 영상을 다 봤거나 자리를 비울 때는 먼저 **중지**합니다.

연결 방식은 [공식 Realtime 번역 가이드](https://developers.openai.com/api/docs/guides/realtime-translation)를 따릅니다.

## 추가 기능: 크롬 댓글 번역(선택)

Chrome에서 TikTok 댓글 아래에 한국어 번역을 붙입니다. 댓글은 같은 키로 **GPT-6 Luna 텍스트 번역**에 보내며, 켤 때만 비용이 듭니다(댓글별 비용은 아직 측정하지 않았습니다). 기본은 꺼져 있습니다.

1. 앱의 **소리·표시 설정**에서 **크롬 댓글 번역(선택) · GPT-6 Luna로 번역, 켤 때만 비용**을 켜고 **번역 설정 적용**을 누릅니다.
2. 자막창의 **틱톡 댓글 번역** 버튼을 눌러 연결 코드를 확인하고 **연결 코드 복사**를 누릅니다.
3. 연결 창의 **Chrome에서 열기**를 누릅니다(안 열리면 **주소 복사** 뒤 Chrome 주소창에 `chrome://extensions` 붙여 넣기) → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 앱 폴더 안 **browser-extension** 폴더를 선택합니다. 폴더 위치를 모르면 연결 창의 **확장 폴더 열기**를 누르거나 Codex에게 물어봅니다.
4. 열려 있던 TikTok 탭을 새로고침합니다.
5. Chrome 도구 모음의 확장 버튼을 눌러 연결 코드를 붙여 넣고 **저장하고 켜기**를 누릅니다. 댓글을 열면 영어·스페인어 댓글 아래에 한국어가 붙습니다.
6. 끌 때는 확장에서 **일시정지**를 누릅니다. 앱 설정의 댓글 번역을 끄면 API 전송도 멈춥니다.

자막 앱은 켜 둡니다. 댓글만 볼 때는 **번역 시작**을 누르지 않아도 됩니다. 댓글 본문 글자만 보내고 작성자·프로필은 보내지 않습니다. 연결 코드는 본인 PC의 앱과 확장 사이 연결용이니 다른 사람에게 공유하지 마세요. Chrome 웹 전용이며, 실제 TikTok 화면에서의 동작은 아직 검증 전입니다. 사이트 화면이 바뀌면 번역이 안 붙을 수 있습니다.

## 화면 조작

- 창에 **이번 실행의 API 누적 예상 비용(USD)**이 표시됩니다. 앱을 완전히 종료하면 초기화됩니다. 캐시 할인·세금은 반영하지 않습니다.
- 이미 번역 중이면 시작 버튼은 **번역 중**으로 표시됩니다. 설정을 바꾸려면 먼저 **중지**를 누르세요.
- 새 영상은 **새 영상** 또는 `Ctrl+Shift+R`, 중지는 `Ctrl+Shift+S`입니다(단축키는 Windows만, Mac은 창의 버튼). 영상 위 자막은 별도로 이동하거나 위치를 고정할 수 있습니다.

## 소리가 안 들어올 때

**중지 → 소리·표시 설정 → 새로고침 → 실제 소리가 나오는 장치 선택 → 번역 시작**으로 다시 연결합니다. Windows 기본 출력과 브라우저/앱별 출력이 다를 수 있습니다. 이어폰·USB 장치를 바꾼 뒤에는 다시 선택하세요. 영상 일시정지·브라우저 음소거도 확인합니다. Mac은 소리 출력이 **다중 출력 장치**인지, 앱에서 **BlackHole 2ch**를 골랐는지 확인합니다.

## 전송 범위와 알려진 제한

- 마이크 대신 선택한 **출력 장치의 전체 소리**를 받습니다. 특정 브라우저 탭 하나만 분리하는 기능은 아닙니다. 회의·통화 전에는 먼저 중지하세요. 자막·음성을 자동 저장하지 않습니다.
- API 요청을 자동 재시도하지 않습니다. 중지를 눌러도 이미 제출한 요청과 과금은 취소되지 않을 수 있습니다.
- 숫자·부정·전문 용어처럼 중요한 내용은 원문과 함께 확인하세요.
- 개발 PC에서 실행·번역을 확인했지만, **새 PC의 처음부터 끝까지 설치는 아직 검증하지 않았습니다.** Windows 설치는 개발 PC의 새 가상환경에서 재현했고, Mac은 실제 기기에서 실행해 보지 않았습니다. 단일 EXE가 아닌 소스·설치 도구 배포본입니다.

## 부록: 본인 OpenAI 키 만들기 (체험 키가 끝난 뒤)

1. [OpenAI Platform](https://platform.openai.com/)에 본인 계정으로 로그인합니다. ChatGPT 구독과 API 사용료는 별도입니다.
2. 조직 결제 설정에서 사용 가능한 크레딧이나 결제 수단을 확인합니다. 결제가 필요하면 금액과 자동 충전 여부를 읽고 직접 선택합니다. 가입만으로 무료 API 사용이 보장되지는 않습니다.
3. 프로젝트 선택 메뉴에서 본인 번역앱용 프로젝트를 선택하거나 만듭니다. 회사 관리 계정에서 권한이 없다면 관리자에게 문의합니다.
4. 선택한 프로젝트의 **API Keys → Create new secret key**에서 키를 만듭니다. 키 권한을 제한하는 경우 번역 API에 필요한 권한을 허용해야 하며, Read Only 키는 맞지 않습니다.
5. 표시된 키를 직접 복사하여 앱의 가려진 API 키 입력칸에 붙여 넣습니다. 새 키는 다시 전체 값을 볼 수 없으므로 필요하면 본인의 안전한 비밀값 보관 도구에 보관합니다. Codex 채팅·GitHub·스크린샷에는 넣지 않습니다.
6. 프로젝트 **Limits → Spend → Edit spend limit**에서 원하는 월별 금액을 정하고, 사용 차단을 원하면 **Enforce a hard limit**을 켠 뒤 저장합니다. 알림만 설정하면 요청이 차단되지 않습니다.
7. 앱에서 짧게 번역한 뒤 중지하고 [Usage](https://platform.openai.com/usage)에서 사용량을 확인합니다. 앱 예상 비용과 최종 청구액은 다를 수 있습니다.

공식 안내: [프로젝트·키 발급](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform), [월별 강제 한도](https://developers.openai.com/api/docs/guides/spend-limits). 화면 이름은 계정·권한·제품 변경에 따라 다를 수 있습니다.
